# Advanced Bank Term Deposit Analysis

A Jupyter Notebook project exploring customer characteristics and campaign factors associated with term-deposit subscriptions using Python, Pandas, Matplotlib, and Seaborn.

## Project files

- `Advance_Bank_Term_Deposit.ipynb` — exploratory analysis and visualizations.
- `data.csv` — dataset used by the notebook.
- `requirements.txt` — Python dependencies.
- `.gitignore` — excludes local environments, Jupyter checkpoints, secrets, and temporary files.

## Setup

Use Python 3.10 or newer. From this folder, install the dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run the notebook

Keep `data.csv` in the same folder as the notebook, then run:

```bash
jupyter notebook
```

Open `Advance_Bank_Term_Deposit.ipynb` and execute the cells in order.

## Analysis topics

The notebook explores customer demographics, job distribution, balance and deposit trends, campaign/contact effectiveness, and relationships among numeric features.

## Data note

Before publishing the dataset, confirm its source, redistribution terms, and license. Do not include confidential customer or bank records.
